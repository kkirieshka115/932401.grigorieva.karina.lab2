## Что было сделано

- Стили подключены тремя способами: основной код вынесен во внешний файл `style.css`, для заголовков использован внутренний тег `<style>`, а к форме добавлен inline-стиль (`opacity: 0.9`).
- В `:root` заданы CSS-переменные для основной светло-голубой и акцентной тёмно-синей цветовой гаммы.
- Использованы разные типы позиционирования: `static` для стандартных блоков, `relative` для карточек проектов и `absolute` для меток внутри них.
- Реализованы интерактивные состояния элементов: свечение карточек изнутри при наведении (`:hover`), изменение их прозрачности при клике (`:active`), подсветка полей формы при фокусе (`:focus`) и изменение цвета посещенных ссылок (`:visited`).
- Для бокового блока `<aside>` применен эффект матового стекла с помощью свойства `backdrop-filter: blur`.
