Вариант: 15

В этой лабораторной работе я оформила страницу из первой лабы с помощью CSS. Стили подключены тремя способами: внешний файл style.css, внутренний блок style для заголовков и inline-стиль для формы. В :root заданы CSS-переменные для цветов — светло-голубой основной и тёмно-синий акцентный. Для основных блоков использовано позиционирование static, для карточек проектов — relative и absolute. У aside применён эффект матового стекла через backdrop-filter: blur. При наведении на карточки появляется свечение изнутри, при клике меняется прозрачность. Поля формы подсвечиваются при фокусе, ссылки меняют цвет после посещения.

Чтобы открыть сайт, нужно запустить index.html в браузере.
